Dawn Patrol on Windows

Open the surf forecast in its own app window, with Start Menu and Desktop shortcuts. It uses Microsoft Edge or Google Chrome, which are already on most PCs.

Install from PowerShell

Open PowerShell (no admin needed) and paste this line:

& ([scriptblock]::Create((irm https://dawnpatrol.casadelfuego.org/windows/DawnPatrol.ps1))) -Install

It adds a Dawn Patrol shortcut to your Start Menu and Desktop, then opens the app. Your spots and settings are the same as in your browser.

Other ways to use it

  1. Open the app window without installing: replace -Install with nothing.
  2. Choose a browser or size: add -Browser Chrome or -Width 1000 -Height 700.
  3. Remove everything: replace -Install with -Uninstall.
  4. No PowerShell: in Edge, open the site, then Settings > Apps > Install this site as an app.

You can read the script first at /windows/DawnPatrol.ps1. It is plain text and only creates shortcuts and opens the site.
